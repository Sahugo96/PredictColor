# Event Prediction Neural Network

Проект для предсказания событий с использованием нейронной сети.

## Задача

По данным логгера рулетки (`data/*.xlsx`) предсказать цвет следующего исхода
(red / black / green) и выйти за 55% точности.

## Важная находка по данным

В файле колонка **«Число»** (x) связана с цветом **детерминированно**:
цвет практически полностью задаётся зоной `int(x*100)` (100 зон от 0 до 99).
Именно поэтому:

| Подход | Точность на тесте |
|---|---|
| Зонная таблица (`int(x*100) -> цвет большинства`) | ~97% |
| Нейросеть FFN по one-hot зоны x | ~97% |
| LSTM по истории цветов | ~50% |
| Baseline «всегда чёрный» | ~47% |

История предыдущих цветов практически не несёт прогностической силы
(переходы в данных близки к независимым), а вот число x позволяет
предсказывать цвет с точностью ~97%.

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Положите файл данных (xlsx/csv/json) в каталог `data/`.
4. Запустите:
```bash
python app.py
```

## Структура проекта

- `app.py` — основной пайплайн: загрузка -> предобработка -> обучение -> оценка
- `config.py` — конфигурация (пути, гиперпараметры, зоны)
- `modules/event_predictor.py` — нейросети: FFN (по зоне x) и LSTM (по истории)
- `utils/data_loader.py` — загрузка xlsx/csv/json
- `utils/preprocessing.py` — чистка, зоны, one-hot, окна для LSTM
- `data/` — каталог исходных и обработанных данных
- `models/` — сохранённые модели (.keras)
